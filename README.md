# AI Airport Companion

Mobile-first PWA + FastAPI backend system with a local LLM (Gemma via Ollama), RAG pipeline, graph-based navigation, and a context engine.

## Local development

Repo root, with [Python](https://www.python.org/) and [Node.js](https://nodejs.org/) on your PATH:

```bash
npm run setup
npm run dev
npm run api
npm run test
```

Use two terminals for `dev` (frontend) and `api` (backend).
